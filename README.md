# Hái Hoa Tặng Cô Phương Anh 🌸

> Web ứng dụng tương tác học tập – Toán 8 – Luyện tập chung (Bài 7, Bài 8) chào mừng Ngày Nhà giáo Việt Nam 20/11.

## 🔗 Trải nghiệm trực tiếp (Live Demo)
👉 **[https://tungcanxuan-byte.github.io/hai-hoa-tang-co/](https://tungcanxuan-byte.github.io/hai-hoa-tang-co/)**

## ✨ Các tính năng chính
- **Chặng 0 - Khởi động**: Chào mừng, giới thiệu hành trình tri ân 20/11.
- **Chặng 1 - Sơ đồ tư duy**: 7 hằng đẳng thức đáng nhớ dạng hoa 7 cánh lật mở tương tác, bộ đếm giờ thuyết trình & chấm điểm nhóm.
- **Chặng 2 - Khối 3D trực quan**: Mô hình 3D lập phương cắt thành 8 khối giải thích hằng đẳng thức `(a + b)³` và `(a - b)³`, hỗ trợ xoay và tách khối.
- **Chặng 3 - Vườn hoa tri ân**: Trò chơi hái hoa trả lời câu hỏi Toán 8 nhận hoa may mắn.
- **Chặng 4 - Vận dụng thực tế**: Mô hình 3D bể cá thể tích và thử thách khối Rubik bóc lớp sơn.
- **Chặng 5 - Bó hoa tri ân**: Tổng kết bảng xếp hạng thi đua các nhóm, gửi lời chúc 20/11 lên bảng tri ân tặng cô Phương Anh.

## 💻 Công nghệ
- HTML5, CSS3 3D Transforms, Web Audio API (âm thanh hiệu ứng tích hợp không cần file ngoài).
- Responsive, hoạt động mượt mà trên mọi thiết bị & máy chiếu lớp học.
